MOPAC is available as a free Android app in the [Google Play Store](https://play.google.com/store/apps/details?id=cz.m).
This version of MOPAC contains a simple GUI for viewing and manipulating input and output files.
However, it is not based on the lastest open-source version of MOPAC, so it may be missing recent features and bug fixes.
