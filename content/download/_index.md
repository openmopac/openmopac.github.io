This version of MOPAC is distributed under the open-source [Apache 2.0 license](https://github.com/openmopac/mopac/blob/main/LICENSE),
and the source code of MOPAC can be downloaded from its GitHub [repository](https://github.com/openmopac/mopac).
MOPAC can also be obtained through several other distribution channels. See below for links to more information on how
to download and install MOPAC.

Please cite the use of MOPAC in scientific publications with a software citation to its [Zenodo DOI](https://doi.org/10.5281/zenodo.6511958).
Note that there will soon be an open-source MOPAC release paper in the Journal of Open-Source Software to replace this software citation as the recommended citation for MOPAC.
